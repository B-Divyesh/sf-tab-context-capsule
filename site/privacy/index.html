Privacy, by construction.

Tab Context Capsule is a local-first browser extension. We designed it so your browsing context does not need to reach us.

What the extension stores

Capsule names, next steps, selected page titles, URLs, notes, ordering, timestamps, and optional color labels are stored in your browser’s local extension storage. A private-window URL is included only when you explicitly opt in for that capture. The opt-in itself is not remembered.

What we receive

We do not receive capsule data, browsing URLs, history, notes, or exports. The extension has no analytics or advertising SDK. It requests only tab access, to read the current window and reopen saved pages, and local storage access.

Exports and deletion

Markdown and JSON files are created on your device. They may contain sensitive links; you control where they go. Delete capsules from the library or uninstall the extension to remove local data. A deleted capsule has a short in-app Undo action.

Licenses

If you buy Conductor, Sociobot/Dodo processes checkout as merchant of record. The extension sends only the license token to Sociobot for verification at most once per day; it does not attach capsule or browsing data. The token and cached verdict are stored locally.

Contact

Questions can be filed in the public issue tracker. This policy will be updated here if the product’s data practices change.
