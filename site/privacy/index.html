Privacy policy

Tab Context Capsule stores your saved browser context locally so it does not need to reach us.

Data the extension stores

Capsule names, next steps, page titles, URLs, notes, ordering, timestamps, and color labels stay in local extension storage.

A private tab is included only when you choose it for that capture. The extension does not remember that choice.

Data we receive

We do not receive capsule data, browsing URLs, history, notes, or exports.

The extension has no account, analytics, advertising SDK, content script, or host permission.

Exports and deletion

Markdown and JSON files are created on your device. They may contain sensitive links, so choose where you share them.

Delete capsules from the library or uninstall the extension to remove local data. A deleted capsule has a short Undo action.

Demo data

The web demo uses only the demo:tab-context-capsule: browser-storage prefix. Resetting or leaving the demo discards that sample data.

License checks

If you buy Conductor, Sociobot/Dodo processes checkout as the merchant of record.

The extension sends only the license token to Sociobot. Automatic checks run at most once per day.

The token and cached verdict stay in local browser storage. Capsule names, notes, and URLs are never attached.

Contact

Ask a privacy question in the public issue tracker.
