How it works

Save enough context to resume

The extension records your own notes. It does not generate summaries or use cloud sync.

  1. 01

    Select tabs

    Choose useful tabs from the current window. Private tabs are excluded by default.

  2. 02

    Add the purpose

    Name the project, add a note to each page, arrange the order, and record the next step.

  3. 03

    Save or share

    Close originals only after you confirm. Reopen later, or export readable Markdown and lossless JSON.

Privacy

Capsule data stays in your browser

The extension has no account or analytics. It does not transmit capsule URLs, names, notes, or exports. Private tabs require a new choice for each capture.
